Project Name: SafeKeep
Role: Full Stack / Backend Developer
Project Description: A highly secure "Digital Dead Man's Switch" and legacy platform that allows users to encrypt and store sensitive information (passwords, documents, instructions). The system automatically releases these encrypted assets to designated trusted recipients if the user fails to "check in" within a configurable timeframe.

--- TECH STACK ---
Backend: Java 21, Spring Boot 3.3.2, Spring Security, Spring Data JPA, Hibernate
Database: PostgreSQL, Flyway (for migrations)
Security & Cryptography: BouncyCastle (Argon2id for key derivation), AES-256 (client-side zero-knowledge architecture focus), JWT (JSON Web Tokens)
Background Processing: Quartz Scheduler (JDBC JobStore for clustered, fault-tolerant background jobs)
Other Backend Tools: Bucket4j (Rate Limiting), Zip4j (Secure ZIP handling), Mailgun/SMTP (Thymeleaf email templates), Swagger/OpenAPI
Frontend: React 19, Vite, TanStack Query (React Query), Zustand, React Router DOM, React Hook Form
UI/UX: Framer Motion (Animations), custom CSS architecture (Glassmorphism, Bento-grid layouts), Lucide React (Icons)
Networking: Axios (with robust JWT interceptors)

--- KEY WORKFLOWS YOU BUILT ---
1. The Check-in System: Users ping the server to reset a countdown timer. 
2. The Vault: Users upload files/text encrypted with a client-side password. The server stores the ciphertext.
3. The Scheduler: A Quartz job runs every 15 minutes to evaluate all users. If a user's timer expires + grace period elapses, the system triggers the "Release" state.
4. The Release: The system automatically generates unique secure access links and emails them to the user's pre-configured recipients.
